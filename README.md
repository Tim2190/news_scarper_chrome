# Каталог видеоархива ← новости nazarbayev.kz

Инструменты, чтобы подтягивать описания событий с сайта https://nazarbayev.kz/ru/news в каталог
видеоархива Фонда (ID = имя файла в Avid | Дата | Описание).

## Что лежит в репозитории

| Путь | Что это |
|---|---|
| `output/Каталог_2019_апрель.xlsx` | **Каталог партии «апрель 2019» (99 файлов, 26.03–29.07.2019)** — та же структура. Имена файлов переписаны со скриншотов: `input/Список_2019_апрель.txt`. |
| `output/Каталог_2019_май.xlsx` | **Готовый каталог партии май 2019 (81 файл).** Лист «2019» — в формате основного каталога (ID / Дата / Описание = заголовок и полный текст новости с сайта + тип материала и оператор); лист «Подробно» — ссылка, заголовок и полный текст новости, тип материала, оператор, что проверить (жёлтые строки); лист «Новости сайта» — все новости за период. |
| `data/news.json`, `data/news.csv` | **Весь архив новостей сайта** (572 новости, 20.03.2019 – 25.09.2026; все 354 дня из календаря сайта): дата, рубрика, заголовок, ссылка, полный текст. |
| `data/matches_2019_*.json` | Какой файл к какой новости привязан и с какой уверенностью. |
| `data/batches/*.json` | Ручные уточнения по партиям: исключённые файлы, выбранные вручную новости, свои подписи, пометки «проверить». |
| `extension/` | Расширение Chrome «Архив новостей nazarbayev.kz» — сбор новостей и сопоставление прямо в браузере. |
| `scripts/` | То же самое из командной строки (Node.js + Python). |
| `test/` | Тесты на реальных страницах сайта (`test/fixtures`). |

## Как устроен сайт (проверено)

* Контент отдаётся сервером в обычном HTML (Drupal 8), JavaScript для него не нужен. robots.txt: `Allow: /`.
* Лента: `/ru/news?page=N` (N с 1, по 10 новостей), ссылка на следующую страницу — `.pager a[rel=next]`.
* Фильтр по дню: `/ru/news?date=ДД.ММ.ГГГГ`. Список всех дней, за которые есть новости, зашит в каждую
  страницу (функция `getActiveDates` календаря) — первые новости от 20.03.2019.
  **Особенность:** для части дат (с конца 2021 г. и новее) фильтр возвращает пустую страницу. Такие
  новости и скрипт, и расширение автоматически добирают обходом общей ленты.
* У новостей рубрики «Решения» текста нет — вся новость в заголовке.
* Карточка в ленте: `.view-news .views-row` → `a[rel=bookmark]`, `.item-date`, `.item-title`.
* Новость: `article.node--view-mode-full` → заголовок `.section-title h1`, дата — последний пункт
  `.nav-breadcrumbs`, рубрика `.field--name-field-news-type`, текст `.field--name-body p`.
* Адреса новостей бывают двух видов: `/ru/news/2019-05/<slug>` (старые) и `/ru/<slug>-<число>` (новые).

Почему не работала первая версия расширения: она брала первый `<h1>` на странице (это заголовок раздела
«Новость»), первый `<article>` (это превью в выпадающем меню, без текста), ловила пункты меню
(«Астана» — `/ru/astana-1485348`) за новости и не узнавала старые адреса `/ru/news/2019-05/…`.

## Расширение Chrome

Установка: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `extension`.

* **Собрать за период** — по фильтру даты сайта, только нужные дни (быстро; можно оставить даты пустыми = всё).
* **Собрать всю ленту / продолжить** — обход `/ru/news?page=1,2,…`, продолжает с места остановки.
* **Обновить (только новое)** — с первой страницы до страницы, где новых новостей нет. Для регулярного
  пополнения базы достаточно этой кнопки (или `node scripts/crawl.js <последняя дата> <сегодня>`).
* **Повторить неудачные**, **Пауза**, **Скачать CSV за период**.
* **Сопоставить с каталогом…** — вставьте имена файлов (`dir /b > список.txt`) или две колонки
  «ID | Дата» из Google Таблицы → для каждого файла подбирается новость (та же дата ± 2 дня, совпадение
  фамилий и ключевых слов с учётом транслита: Chavychoglu ≈ Чавушоглу, Kalijanovym ≈ Калижанов).
  Вариант можно поправить в выпадающем списке, результат — «Копировать для Google Таблиц» или CSV.

Между запросами пауза 1,2–2 с, при 429/5xx — повтор с ожиданием.

## Командная строка

```bash
npm install                       # Playwright (Chromium) — разбор тем же DOMParser, что в Chrome
node scripts/crawl.js 01.05.2019 31.05.2019          # дописывает новые новости в data/news.json
node scripts/news_to_csv.js data/news.json data/news.csv
node scripts/match_catalog.js список.txt data/news.json > data/matches.json
python3 scripts/build_catalog.py список.txt data/matches.json data/news.json data/batches/партия.json output/каталог.xlsx
# вместо список.txt можно черновик.xlsx (ID | Дата | Описание | Тип | Оператор); для списка тип съёмки
# и оператор берутся из имени файла
npm test
```

В облачном окружении Claude Code для Node нужен `NODE_USE_ENV_PROXY=1` (иначе `fetch` не ходит через прокси).

* **Kalijanov** → академик Уалихан Калижанов. **Chigeo Katsy** → Шигео Катсу. **B.Saparbaeva** → Бердибек Сапарбаев.
* **Sarkisyan, 28.05** → Председатель Коллегии ЕЭК **Тигран Саркисян**, а не Президент Армении (в черновике ошибка).
* **Centr Zelenyh Tehnologii, 13.05** → посещение Елбасы Международного центра зелёных технологий и инвестиционных проектов.
* **21.06.19 Almaty Konferenciya** — дата верная: 21.06.2019 конференция «30 лет лидерства».
* **PRK** = Президент РК К.-Ж.Токаев. «Foto Elbasy i PRK» — церемония фотографирования Елбасы и Токаева на АЭФ.
  «PRK i D.Tusk» — встреча Токаева с Туском, без Назарбаева: из этого каталога исключён.
* **17.05 AEF bez Elbasy** — второй день форума; отдельной новости нет, ссылка на новость об АЭФ 16.05.
* Файл «Elbasy vruch diplomov NU. Otkr-e atletich.centra» содержит два события — даны обе ссылки.

ID в каталоге пока взяты из черновика (набраны со скриншотов). Когда будет точный список
`dir /b`, прогоните `match_catalog.js` + `build_catalog.py` по нему — или вставьте список на странице
«Сопоставить с каталогом».
